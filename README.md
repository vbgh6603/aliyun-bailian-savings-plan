## 阿里云百炼节省计划是怎么运作的

它是“承诺消费换折扣”的后付费折扣方案。你选定一个期限（3 个月、6 个月、12 个月或 24 个月）和每月承诺金额，平台按月给你发放对应额度，调用费用按折扣从额度里扣；同类额度全部用完后，超出部分自动转回按量付费，服务不会中断。

几个核心特征：

- **覆盖面**：抵扣阿里直供的全部模型——千问系列、向量与排序模型、图像语音视频类模型，以及 DeepSeek、Kimi、GLM 这类三方模型中的阿里直供版本，一次购买跨模型通用
- **折扣阶梯**：承诺金额越高、周期越长，折扣越深，上限 5.3 折
- **自动化程度高**：下单后可立即生效或指定时间（按小时）生效，无需手动激活或绑定，支持自动续费

用起来的体验和按量付费几乎没有区别，区别只体现在账单上：同样的调用量，花的钱变少了。

## 周期、金额、付款方式：三个决定折扣的旋钮

一份节省计划的最终折扣，由承诺周期、每月承诺金额和付款方式共同决定，三个都得过一遍再下单。

**承诺周期**：3 个月、6 个月、12 个月、24 个月四档，周期越长折扣越深。拿不准用量就先买 3 个月试水，别一上来锁两年。

**每月承诺金额**：按国内站的规则，最低 1000 元/月起，以 10 元为单位递增，不设上限，实际档位以购买页实时展示为准。这个数建议按你最近几个月账单的平均值定，原因见后面的坑一。

**付款方式**：

- 全预付：一次性付清整个承诺周期的金额，折扣最大
- 零预付：购买时不付钱，之后按月支付承诺金额，折扣略低一档，且需要联系商务经理开通

还有一点容易忽略：折扣是按模型类别分开算的。A 类（千问系列、文本向量、多模态向量、排序模型、行业模型、Function Call 等原生工具调用）折扣最优；B 类（图像生成、语音合成、语音识别与翻译、视频生成与编辑）低一档；C 类（DeepSeek、Kimi、GLM、MiniMax 等）只有阿里直供版本能抵扣，三方直供版不在范围内。同一个计划里不同模型的实际折后价并不一样，每一档的具体数字进购买页看实时报价最准。👉 [进购买页核对各档位的实时折扣](https://bit.ly/aliyun-coupon)

## 抵扣范围：这些钱能省，这些不能

节省计划只覆盖推理侧的按量费用，训练和部署完全不在范围内。

能抵扣的：

- 模型调用费（输入和输出 Tokens）
- 模型原生工具调用（Function Call、网页抓取等）
- 上下文缓存（Context Cache）
- 批量推理（Batch）

不能抵扣的：

- 模型调优（微调训练）费用
- 模型部署费用
- 联网搜索插件、MCP 广场、通义深度搜索、案例检索等插件或工具费用
- Qoder CN（该产品仅支持 Credits 调用）

知识库（RAG）的边界值得单独说一句：向量化（Embedding）和重排（Rerank）产生的模型调用费属于 A 类，可以正常抵扣；但知识库本身的规格费——标准版 0.03 元/知识库/小时、旗舰版 0.2 元/RCU/小时——属于资源占用费，不在抵扣范围，得走资源包或按量付费。如果应用里挂着好几个知识库常驻运行，这笔规格费不算小，做成本预算时别漏掉。

## 扣费顺序，以及四个容易踩的坑

百炼的扣费有一套固定顺序，节省计划排在比较靠后的位置：

> 免费额度 → 资源包 → 其他模型节省计划 → AI 通用型节省计划 → 按量付费

免费额度和资源包用完，才轮到节省计划的额度；全都耗尽后，超出部分自动转按量付费。如果同时持有多个同类型节省计划，先到期的先抵扣，到期时间相同则先购买的先抵。

**坑一：额度按月发放，不是一次性给总量。** 订 3 个月、每月 1000 元的计划，拿到手的是每月独立的 1000 元额度，当月没用完的部分到期清零，不会滚存到下个月。这也是承诺金额不建议定太高的原因——承诺 3000 元实际只用 1500 元，等于每个月白扔一半。

**坑二：周期是“动态月”，和自然月对不上。** 额度从生效日起每满一个月重置一次，并非每月 1 号刷新。15 号买的计划，每月 15 号左右重置，对账时别按自然月算。

**坑三：出账有 2~10 分钟延迟。** 额度扣减按实际出账时间算，不按任务提交时间算。可能出现的情况是：控制台显示额度还有剩，但出账那一刻计划已过期或额度已耗尽，这部分调用直接按量扣费。官方给的建议是把消费预警阈值设高一点，留出缓冲。

**坑四：开了“免费额度用完即停”会挡住节省计划。** 这个功能（也叫安心模式）会让服务在免费额度耗尽时直接停止，节省计划根本没机会接管。想让折扣正常生效，记得去模型设置里把这个开关关掉。

## 常见问题

**承诺 1000 元/月，是先预存 1000 元吗？**
取决于付款方式。全预付是一次性付清整个承诺周期的总额；零预付购买时不付钱，之后按月支付。无论哪种，额度都按月发放，扣费时按折后价从当月额度里扣。

**当月额度没用完，能退吗？**
不能。月周期结束时剩余额度自动过期，不累积、不退还。

**用量超过当月额度怎么办？**
超出部分自动转按量付费，服务不中断，账单会分成“节省计划抵扣”和“按量付费”两块。

**节省计划和 Coding Plan 是一回事吗？**
完全是两个产品。Coding Plan 是面向 AI 编程的订阅制方案，固定月费给月度请求额度，Lite 首月 7.9 元、Pro 首月 39.9 元，支持 Qwen3.5-Plus、qwen3-coder-plus 等编码模型；节省计划抵扣的是百炼平台按量计费的调用费，两者面向的场景不一样。

**不想承诺消费，还有别的省钱办法吗？**
两个：对实时性没要求的任务改用 Batch 批量调用，输入输出单价按实时推理的 50% 计费；多轮对话、长文档问答场景开上下文缓存，重复出现的输入只计部分费用。注意这两个不能同时生效，二选一。
